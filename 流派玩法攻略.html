🐾 花光首富的钱 · 流派玩法攻略

肉鸽消费模拟 · 15 流派 · 前 / 中 / 后 卡组与平衡推演

目标：规定天数内花光首富的钱 核心循环：花得多 → 出好卡 → 花得更多 真正约束：行动点 AP

一、核心机制速览

先记住五条，再看卡组。搞错这五条，卡组再好也花不光。

① 消费场景
商场 / 4S店 / 进口商。每天有「预算上限」，次日自动恢复，不随剩余资产收缩。选「上限」档一次花光当天预算。
② 资产市场
房产 / 物资 / 艺术 / 球队。无日预算上限，买入即囤。每天涨跌 / 收租 / 暴跌；暴跌平仓亏的本金才是真正花掉的钱。
③ 投资场景
投资公司（需先买写字楼）/ 股票。投出去的钱每天分红回流（坏消息），只有公司倒闭 / 股票暴跌平仓才真正消失。
④ 行动点 AP
每天有限，是真正的约束。高 AP 卡 + 批量购买减耗卡 = 一天扫更多场景。
⑤ 卡牌六型
一次性消费 / 事件卡 / 短期增益（都不占槽）；流派主卡 / 稀有功能卡（占槽，需装备）。刷新流用积分抽消耗卡、可复制。
💡 设计铁律：光靠买东西花不光。必须靠「一次性巨额消耗卡 + 永久增益卡 + 批量购买」三件套；而没有一次性巨额花费，除非卡组齐全——红卡 / 金卡的掉率与你的花费指数成正比，所以越会花，越容易凑齐卡组。

四、平衡推演（为什么必须凑齐卡组）

每日消费场景预算 = 初始资产 ÷ (总天数 × 0.5) × (该场景权重 ÷ 权重和) 权重：商场 0.30 · 4S 0.34 · 进口 0.36 （合计 1.0） 例：$200B / 50 天 → 单日总预算 = 200B ÷ 25 = $8B 　商场 $2.4B / 4S $2.72B / 进口 $2.88B （资产市场无此上限，仅受 AP 约束）
  • 消费场景只能「匀速」花：每天上限固定、次日恢复。整局消费场景总预算≈初始资产的 2 倍，但你要 50 天每天点满「上限」才花得完，且稀缺涨价让后期单日越买越少——光靠它又慢又难收尾。
  • 资产市场才是后期主战场：房产 / 物资 / 艺术 / 球队没有日预算上限，只受 AP 限制。买得越贵（囤房 / 囤物红卡抬高买入价），暴跌平仓亏的本金越多，净消耗 = 买入价 − 回款。
  • AP 是真正瓶颈：没 AP 卡，一天扫不了几个场景；高 AP 卡（r_ap / k_f1）+ 批量减耗（p_f2 / p_f4 / r_cost1）才能把一天「榨干」。
  • 一次性巨额花费被稀有度锁死：万物皆可拍卖（资产的 15%）、任性撒钱（8%）、薛定谔（70% 翻倍）、黑洞信用卡（×2）都是红卡；它们的掉率与你的花费指数成正比——越会花 → 越容易出红卡 → 一次性清空残局。卡组不全时根本抽不到，所以「没有一次性巨额花费，除非卡组齐全」成立。
  • 随机性受控：事件基础概率已下调（0.10 + eventRate×0.5，封顶 0.5），避免太频繁；奖励与花销成正比（花越多给越好的卡）。

五、速通结论

  • 万金油起手：通用（全场景加成）+ 高行动（AP）是任何流派的地基，优先凑。
  • 选一个囤积流派做主 C：囤房 / 囤物 / 艺术 / 球队——它们无日预算上限，是后期清空资产的主力；配齐买入价抬高卡 + 暴跌卡，净消耗爆炸。
  • 刷新流 + 高积分流：提供无限消耗卡燃料，专治「钱花不完但没好卡」。
  • 收尾用规则级红卡：熵增（每日全场景 +3% 累加）、黑洞（每日 −1%）、薛定谔（翻倍）、一次性拍卖（15%）——卡组齐全后一键清空。
